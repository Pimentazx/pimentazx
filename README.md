Sistema web desenvolvido para uma empresa de formaturas, com formulário personalizado para coleta de informações dos alunos, envio de dados por e-mail, upload de imagens e integração com serviços externos.

**Tecnologias:** React, TypeScript, NestJS, Node.js, Tailwind CSS, SMTP e Cloudinary.
 
🌐 [Deploy](https://www.meritoformaturas.com.br/)
